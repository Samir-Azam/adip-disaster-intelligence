# Claude Code — Feature Explanation Mode

The user wants to understand an already-built feature.

For the requested feature, inspect the actual repository and explain:

1. Problem it solves
2. User who needs it
3. End-to-end flow
4. Frontend files
5. Backend files
6. Database tables/queries
7. Redis/queue involvement
8. AI involvement if any
9. Security/authorization
10. Error/failure handling
11. Why this design
12. Alternatives
13. Trade-offs
14. Important code walkthrough
15. How to modify it
16. 60-second interview answer
17. Five interviewer follow-ups
18. Ask the user 3 questions to test their understanding

Do not explain from generic knowledge if the repository can answer the question. Inspect the actual implementation first.
