# Learning Order After Build

The user will learn the completed project in this order:

1. Product/problem and users
2. Overall architecture
3. Repository structure
4. Authentication/RBAC
5. Database/PostGIS
6. Incident lifecycle
7. File/object storage
8. Redis and async jobs
9. FastAPI + AI pipeline
10. Priority engine
11. GIS/map
12. Resource allocation
13. WebSockets/real-time
14. Notifications
15. Security
16. Testing
17. Docker
18. CI/CD
19. Performance/scalability
20. Interview explanation + behavioral stories

For every topic teach:
What → Why → How → Code walkthrough → Alternative → Trade-off → Failure → Interview practice.
