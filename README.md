# ADIP Claude Project Pack v2

This pack is designed for a **complete one-pass implementation** because the developer has limited time.

## Start here
1. Upload this entire folder/ZIP to Claude Code.
2. Tell Claude to read `CLAUDE.md`.
3. Use `prompts/01_BUILD_ENTIRE_PROJECT.md`.
4. After the build, run `prompts/02_POST_BUILD_AUDIT.md`.
5. Then use `prompts/03_FEATURE_EXPLANATION_MODE.md` whenever you want to learn a feature.

## Key difference from v1
Claude should not stop after each milestone. It should build the complete coherent MVP, then create a detailed implementation handbook describing what the code actually does.

## Learning strategy
Build first, understand deeply afterward. The learning order is in `docs/19_LEARNING_ORDER.md`.
